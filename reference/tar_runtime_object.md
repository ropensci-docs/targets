# Get the `tar_runtime` object.

For internal purposes only. Not a user-side function. Do not invoke
directly.

## Usage

``` r
tar_runtime_object()
```

## Value

The internal `tar_runtime` object of class `"tar_runtime"`.

## Details

Manages internal settings that targets need while they run.

## Examples

``` r
tar_runtime_object()
#> <environment: 0x560cd09b2e48>
```
